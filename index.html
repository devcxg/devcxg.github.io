Projects
cxg2 :: active
cxg2 is the game engine I use. Made in C++, it targets windows primarilly. It is not at all technically impressive, but it gives me absolute control while being license free. It utilizes Vulkan 1.3 and uses OpenGL 4.1 as a fallback.

Project "Evax" :: active
I'm not planning to reveal too much about this yet due to how early its development is, but it can be described as an fps with the mechanical skill requirement of CS(valve), Ability mastery requirement of VALORANT(riot), and the Knowledge requirement of a MOBA.

Project "Idols" :: stalled
This project was designed before evax and has a pretty solid (unintentional) connection to it. Depending on needs (aka profit), I may release this as an expansion for evax or as a separate title.

About//faq
Programming languages
C and C++ only. Every time I try to use another language, some niche feature that I use often is missing. C and C++ are the only languages that supports my needs. Though, I stopped caring about languages - there may be a feauture-rich, compiled, low/intermediate-level language out there somewhere now.

Platform Support
Windows is a default platform. As much as I love unix systems and everything about them, there is not enough marketshare to make it worth building for. Most dependencies I use are cross-platform and are generally fine to be built, but they will lack complete testing.
